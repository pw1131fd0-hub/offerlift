# OfferLift PRD — 求職者薪資談判智囊（React 版本）

## 1. 產品願景

OfferLift 是一款專為台灣科技業求職者設計的薪資談判輔助工具。透過輸入 Offer 詳情，使用者可獲得客觀的市場評估分數、具體的談判腳本、以及參考薪資區間，從而掌握談判主動權，爭取應得報酬。不同於一般薪資情報站，OfferLift 強調數據真實性與即時性，透過後端資料庫整合 104、LinkedIn、CakeResume 等薪資情報，並支援用戶匿名貢獻數據，打造最貼近市場行情的薪資談判平台。

---

## 2. 技術架構（2026-04-11 更新）

### 前端重構：單頁 HTML → React 多頁應用
- **建構工具**：Vite 6
- **框架**：React 18
- **路由**：React Router v6（6個頁面）
- **狀態管理**：Zustand（含 localStorage 持久化）
- **樣式**：Tailwind CSS
- **部署**：Docker + Nginx（前端容器 port 8080）

### 後端（不變）
- Node.js + Express + PostgreSQL + Redis
- Port 3000，前端透過 Nginx reverse proxy 訪問

### Docker 部署架構
```
offerlift-postgres  (5432)
offerlift-redis     (6379)
offerlift-api       (3000)  ← Node.js API
offerlift-frontend (8080)  ← Nginx serving React build
                          ↗ API proxy → offerlift-api:3000
```

## 3. User Story

### US-01：求職者評估 Offer 價值
**身份**：正在面試科技公司最後一關的求職者
**我希望**：輸入我的 Offer 詳細結構（底薪、獎金、股票、城市、年資）
**以便**：獲得一個客觀的評估分數（0-100）和針對該分數的談判建議

**接受標準**：
- [x] 輸入必要欄位後點擊評估，3 秒內顯示結果
- [x] 評估分數以視覺化環圈呈現，並附上各項加分/減分原因
- [x] 根據分數給出「果斷接受」「可以談判」「必須談判」三種行動建議

### US-02：求職者取得談判腳本
**身份**：對談判話術沒有把握的初次轉職者
**我希望**：瀏覽並複製針對不同情境的談判對話腳本
**以便**：在與 HR 電話中能從容應對，不失專業形象

**接受標準**：
- [ ] 頁面載明 5 種常見情境（開場、報價低於預期、談判空間、非薪資福利、暫緩決策）
- [ ] 每個腳本皆為可直接使用的對話範文，並附上談判要點提示
- [ ] 支援一鍵複製到剪貼簿

### US-03：求職者查詢市場薪資區間
**身份**：需要市場數據支撐談判立場的轉職者
**我希望**：查詢特定職稱與地區的市場薪資區間
**以便**：在談判時能引用具體數據而非主觀感受

**接受標準**：
- [ ] 顯示至少 12 個常見科技職位的年薪區間（min-max，單位：TWD）
- [ ] 資料來源註明（104、LinkedIn、CakeResume）
- [ ] 用戶可貢獻自己的匿名薪資數據擴充資料庫

### US-04：求職者參與薪資論壇討論
**身份**：希望深入了解薪資行情與談判策略的轉職者
**我希望**：在匿名的薪資論壇中瀏覽、搜尋、發表討論
**以便**：從他人的經驗中學習，不暴露個人身份

**接受標準**：
- [ ] 用戶可發表匿名討論（職位、城市、薪資範圍、談判經歷）
- [ ] 討論串可依公司、職位、城市篩選
- [ ] 所有資料存於 PostgreSQL 資料庫
- [ ] 禁止任何可識別個人身份的資訊（姓名、電話、email）

## 6. 功能優先級分級（P0/P1/P2）

### P0（Must Have - MVP 核心）
1. **Offer 評估器**：輸入 Offer 結構，3 秒內取得 0-100 評估分數與談判建議
2. **談判腳本庫**：5 種情境的立即可用對話腳本，支援一鍵複製
3. **薪資行情查詢**：12 個常見科技職稱的年薪區間（104/LinkedIn/CakeResume 來源）
4. **薪資論壇**：匿名發表/瀏覽討論，杜絕個資暴露
5. **Docker 部署**：一行指令啟動完整棧（API + DB + Redis + Frontend）

### P1（Should Have - 完善體驗）
1. **Offer 追蹤 Dashboard**：新增/編輯/刪除我的 Offers
2. **匿名薪資貢獻**：用戶可貢獻自己的匿名數據擴充資料庫
3. **稅務計算機**：輸入年薪，自動計算所得稅級距與實領
4. **福利計算機**：年終獎金、股票價值等化為現金流
5. **深色模式**：Zustand 持久化，保護眼睛

### P2（Nice to Have - 差異化）
1. **面試進度追蹤**：記錄各公司面試階段與截止提醒
2. **PDF 匯出**：將 Offer 評估結果匯出為 PDF 分享
3. **多語言**：繁體中文、英語、日語三語切換
4. **PWA Service Worker**：離線可用、加載更快
5. **RSS 自動更新**：每小時爬取 104/CakeResume 最新薪資數據寫入 DB

## 7. 非功能需求

| 維度 | 需求 | 指標 |
|------|------|------|
| **效能** | API 回應時間 | P95 < 500ms（evaluate 端點 < 3s） |
| **可用性** | 系統 uptime | 99.5%（不含 DB/Redis 維護窗口） |
| **擴展性** | 同時在線用戶 | 支援 100 並發用戶（API + DB 連線池） |
| **安全性** | API 金鑰驗證 | 所有寫入端點需要 X-API-Key header |
| **安全性** | 敏感資料 | 論壇禁止姓名/電話/email，自動過濾 |
| **資料持久性** | 資料庫備份 | PostgreSQL 每日凌晨自動備份 |
| **響應式設計** | 行動裝置 | 全頁面支援 375px - 1920px 寬度 |

- **主標題字體**：Inter（Google Fonts），粗體，20px+
- **內文字體**：Inter，常規，14-16px

- 背景：`#0F172A`（dark mode body）
- 卡片：`#1E293B`（dark mode card bg）
